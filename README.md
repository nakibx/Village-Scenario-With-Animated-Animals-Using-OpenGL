# Village-Scenario-With-Animated-Animals-Using-OpenGL
This project implements an animated village scene using OpenGL (FreeGLUT) in C++, simulating a complete day-night cycle. The 1400x800 window renders a richly detailed environment including a large house with an animated window light, a big tree, two palm trees, pine trees, a flowing river with ripple animations, fish, a swimming duck, a flying bird, a cat with tail-wagging and yawning behavior, a jumping frog with water splash effects, a skipping-rope girl, sunflower and tomato garden clusters, a sky that transitions smoothly from midnight to sunrise, full daytime, and sunset, an animated sun with rotating rays, a crescent moon with a glow effect, twinkling stars, and moving clouds. The user can control time-of-day and house lighting interactively.
